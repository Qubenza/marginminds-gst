Generate GST-compliant tax invoices, CGST/SGST/IGST breakdowns, and advanced tax summaries for WooCommerce stores.

== Description ==

MarginMinds GST helps Indian WooCommerce store owners handle GST effortlessly.

Configure your business GSTIN, apply CGST/SGST or IGST, collect customer GSTIN at checkout, and generate GST-compliant PDF invoices — all from a single, easy-to-use settings panel.

== Source Code ==
The full source code is available at: https://github.com/Qubenza/marginminds-gst

**Free Features:**

* Configure business GSTIN and legal name
* Enable CGST/SGST or IGST tax types
* Set default GST rate (0%, 5%, 12%, 18%, 28%)
* Inclusive and exclusive tax pricing
* Apply GST based on customer shipping state
* GSTIN field at WooCommerce checkout (optional / required)
* Save customer GSTIN to orders
* Display GST breakdown on cart, checkout, and order summary
* GST details in order confirmation emails
* PDF invoice generation with invoice prefix
* GSTIN printed on invoice
* Attach invoice PDF to order emails
* Dashboard overview

**Coming in Pro:**

* Advanced GST Reports (GSTR-1, GSTR-3B ready)
* HSN / SAC Code Support per product
* Export to CSV / Excel
* B2B and B2C GST Handling
* Priority Support

== Installation ==

1. Upload the `marginminds-gst-invoice` folder to the `/wp-content/plugins/` directory, or install directly through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Ensure WooCommerce is installed and active.
4. Go to **MarginMinds-gst > Settings** to configure your business GST details.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and active for this plugin to work.

= Is this plugin free? =

The core plugin is free. A Pro version with advanced reporting and HSN/SAC support is coming soon.

= Which countries does this plugin support? =

MarginMinds GST plugin is designed specifically for India GST compliance.

= What is a GSTIN? =

GSTIN (Goods and Services Tax Identification Number) is the unique 15-character identifier assigned to every GST-registered business in India.

Please open an issue on our support forum. We aim to respond within 48 hours.
